# Bakery Shop System

## About
The Bakery Shop System is a C++ console-based project that helps users select bakery products and place orders.

## Features
- Display bakery menu
- Select bakery products
- Place customer orders
- Calculate order prices

## Technologies Used
- C++
- Object-Oriented Programming (OOP)

## How to Run
1. Download or clone this repository.
2. Compile `project.cpp` using a C++ compiler.
3. Run the generated program.
